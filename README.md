# Hola Mundo
gestor de tareas con seleccion de opciones
## aciones
pequeña aplicacion para la gestion de tareas
## funcionalidad

1. añadir una nueva tarea
2. listar tareas pendientes
3. cambiar el estado de las tareas
4. borrar tareas

## implementacion

- se usa la **ultima version de java** jdk27
- almacenamiento de tareas en memoria usando ``Arraylist<>``
- gestion del UI con `println` y `Scanner`
